# Planning record

These files preserve the pre-implementation specifications, threat walkthrough, and abstract policy simulation that directed Firebreak's build. Statements such as “proposed” or “unbuilt” describe the historical state when each document was written. The repository root README, tests, and CRE simulation evidence describe the final implemented state.

- `PRODUCT-AND-UX-DECISIONS.md` records the usability and security decisions that constrained scope.
- `IMPLEMENTATION-BLUEPRINT.md` specifies contracts, trust boundaries, invariants, and validation requirements.
- `DESIGN-SIMULATION-RESULTS.json` records the early abstract threat-model simulation and its limitations.
- `IMPLEMENTATION-HANDOFF.md` records the original build order and acceptance criteria.
